# HairMatch

髪質・仕上がり・使用感・香りからヘアケアを探す、HTML・CSS・JavaScriptのプロトタイプです。添付画面設計を参考に、スマートフォン優先で実装しています。

## 起動

Node.js 22以降。外部パッケージのインストールは不要です。

```powershell
npm.cmd start
```

http://127.0.0.1:4173 を開いてください。停止は `Ctrl+C`。`index.html`の直接ダブルクリックではJSON読み込みが制限されるため、ローカルサーバーを使用します。別ポートは `$env:PORT=4174` で指定できます。

## スマートフォンで使う

公開URLは <https://san-j24039-debug.github.io/hairmatch/> です。iPhoneではSafariの共有メニューから「ホーム画面に追加」を選ぶと、HairMatchのアイコン付きでアプリのように起動できます。

`main` ブランチへ変更をpushすると、`.github/workflows/pages.yml` がテスト後にGitHub Pagesへ自動公開します。Web App Manifest、Apple Touch Icon、Service Workerを含むため、ホーム画面起動と一度読み込んだ画面のオフライン表示に対応しています。

## 実装した操作

- 下部タブ：ホーム・診断・商品検索・保存・マイページ。
- 診断全8ステップ、未回答チェック、最重要の仕上がり選択、回答確認。
- 「次へ」は下部ナビの上に固定。未回答項目を表示。
- 診断を閉じてホームから再開。回答と進捗は一つの保存データとして管理。
- 各ステップのURL（`#diagnosis/1`〜`#diagnosis/8`）によりブラウザの戻る・進むに対応。
- 確認画面からの修正は「変更して確認へ」で直接戻る。
- 結果TOP5、カテゴリ切替、詳細、根拠・得点内訳、予算超過の別枠表示。
- 結果を閉じる操作、商品詳細から戻った際のカテゴリ・スクロール位置の保持。
- 商品名・ブランド、購入場所、価格、髪質、仕上がり、キシみにくさ、香りで検索。
- 日本語変換中は検索を確定せず、入力欄を保持。入力確定時は結果だけ更新。
- 検索0件では条件をクリアして再表示できる。フィルターのフォーカスを保持。
- 「保存」でお気に入りと比較を切り替え。比較は最大3件、スマホでは表を横スクロール。
- お気に入り・比較・診断履歴の書き込み失敗を成功として通知しない。未保存表示と再試行ボタンで復旧できる。
- マイページには最新30件の診断履歴。過去の回答・商品情報・得点のコピーを保持。
- 履歴の名前（40文字）とメモ（500文字）、個別削除、削除の取り消し。
- 前回の記録との比較：変わった回答、ベストマッチ、同じ商品の相性スコア差。
- ダイアログは閉じる・キャンセル・Escapeに対応。

## 商品情報

初期6商品について、2026年9月5日に公式情報を確認し、税込価格・容量・掲載成分の一部・画像・出典を登録しました。詳細は [商品情報の出典](docs/product-sources.md) を参照してください。

**相性・使用感スコアは検証用の仮評価です。** 公式情報に掲載されていない成分・配合目的・香りの強さは未確認として扱います。掲載成分は全成分表ではなく、未掲載を「配合なし」とは扱いません。実測に基づく商品推奨の段階ではありません。

- プリュスオー メロウ：シャンプー1,650円 / 450mL。
- プリュスオー リポア：トリートメント1,650円 / 450mL。
- &honey Professional：シャンプー1,870円 / 440mL、トリートメント1,870円 / 445g。公式の案内に合わせサロン系に分類。
- COTA i CARE 7・9：シャンプー3,080円 / 300mL、トリートメント3,410円 / 200g。
- KERASTASE オレオ リラックス：シャンプー4,180円 / 250mL、マスク7,040円 / 200mL。

価格は公式掲載時点の参考税込価格です。画像はローカル検証用に公式サイトから取得し、出典を記録しています。商品画像の権利は各権利者に帰属します。

6ブランド・126個の単品商品を、ブランド一覧 → シリーズ絞り込み → 1ページ12件の一覧で表示します。同じシリーズはシャンプー→トリートメント→集中ケアの順です。カラーシャンプーは掲載対象から除外しています。追加範囲と出典は [商品拡充記録](docs/catalog-expansion.md) を参照してください。「両方」は2種類を一覧に表示する条件で、セット商品ではありません。たとえばメロウのシャンプーとリポアのトリートメントを、個別にお気に入り登録・比較できます。比較は種類を合わせて最大3商品です。

予算はそれぞれの単品価格で判定します。「両方」の診断結果はシャンプーとトリートメントのランキングを分けて各TOP5を表示します。未確認価格は予算内とみなしません。トリートメントにはシャンプーのキシ感・泡立ちを、シャンプーにはトリートメントのすすぎ感を採点しません。評価は現在シリーズ共通の仮スコアをもとに、商品種類に応じて計算しています。

旧版のお気に入りは対応する単品に展開します。旧比較リストは先頭3商品を比較に残し、超過分はお気に入りへ保存したうえで画面で案内します。過去の診断履歴は当時のシリーズ単位の情報を保持し、新しい診断から単品単位で記録します。

商品画像はメロウを基準に600×600pxへ統一し、余白を調整した画像を `assets/images/products/normalized/` に保存しています。元画像も保持しています。既存画像の再生成は `scripts/normalize-product-images.ps1`、追加画像はローカルサーバー起動中に `node scripts/normalize-catalog-images.mjs` を使用します。追加分はChromeでWebPも読み込み、600px四方の内側500pxへ商品を収めます。

## データ構成

| ファイル | 役割 |
|---|---|
| `index.html` / `css/style.css` | 画面の土台、ダイアログ、レスポンシブ表示 |
| `js/app.js` | 画面遷移、イベント、進捗・保存状態 |
| `js/ui.js` | 商品カード・共通表示・出典 |
| `js/questions.js` | 質問定義、選択の整合性 |
| `js/diagnosis.js` | 加重得点、理由、予算状態 |
| `js/products.js` | JSON読み込み、検索、価格 |
| `js/catalog.js` | シリーズから単品への展開、旧保存リストの移行 |
| `js/ingredients.js` | 掲載成分と配合目的 |
| `js/favorites.js` | localStorage操作、IDの追加・解除 |
| `js/history.js` / `js/history-tools.js` | 履歴のコピー、比較、復元 |
| `data/products.json` | アプリで使用する商品データ |
| `assets/images/products/` | 公式掲載画像、画像の出典JSON |
| `scripts/server.mjs` | ローカルHTTPサーバー |
| `scripts/seed.mjs` | 検証用JSONを `products.demo.json` に生成（アプリの商品JSONは上書きしない） |

商品追加は `data/products.json` に一意のIDを持つレコードを追加します。価格は税込数値、容量は文字列、不明値は `null`。成分は `{name, category, purpose, sourceUrl}`、出典は `{url, label, checkedAt}` で管理します。スコアのキーは既存商品を参考に0〜100で登録してください。

診断は `Σ(得点×重み) / Σ重み`。最重要の仕上がりと、キシ感が「絶対に嫌」のときの評価は重み8です。未確認の香り系統・強さはその項目の相性計算に含めません。

## 保存と互換性

- `hairmatch:session`：回答、現在のステップ、修正モード、診断完了状態。
- `hairmatch:favorites` / `hairmatch:compare`：商品ID。
- `hairmatch:history`：当時の回答・商品・結果・名前・メモ。
- `hairmatch:undoHistory`：削除を取り消すための履歴。

旧版の回答・保存商品も読み込めます。旧版で直近の完了結果のみが保存されていた場合は「以前の診断（日付未記録）」として引き継ぎます。履歴を見るだけでは現在の回答を変えません。削除した履歴を旧データから勝手に復活させません。

保存失敗時の最新状態はタブ内のメモリに保持し、再試行で保存します。未保存のままタブを閉じた場合は永続化できません。アカウント・端末間同期・PHP/MySQLは未実装です。

## テスト

```powershell
npm.cmd test
# サーバーを起動した別ターミナルで（WindowsのローカルChrome使用）
node tests/browser.mjs
node tests/usability.mjs
node tests/brand-browser.mjs
node tests/brand-entry-browser.mjs
```

ロジックテスト32件、基本操作の回帰テスト、改修箇所のクリック操作テストを実施しています。操作テストは隔離したChromeプロファイルを使用し、通常のユーザーデータを書き換えません。キャプチャとテスト用プロファイルは `test-results/` と `.tmp/`（Git対象外）に生成します。

検証幅は320・390・768・1440px。実機の日本語IME・Safari・スクリーンリーダーは未検証です。元の問題と改修後の結果は [操作テスト報告](docs/usability-audit.md) を参照してください。

ブランド入口とシリーズ切り替えの確認・修正内容は [ブランド入口の動作確認](docs/brand-entry-audit.md) を参照してください。
