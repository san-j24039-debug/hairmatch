# ブランド入口とシリーズ選択の確認（2026-09-07）

## 確認できた状態

新しいChromeプロファイルで「ブランド一覧 → plus eau」を開くと、修正前の公開版・ローカル版ともメルティのシャンプーとトリートメントを含む11商品が表示された。ユーザーの端末での「直接開くとメルティがない」という状態そのものは再現できていない。

関連操作で、実際の条件不整合を再現した。

1. plus eauで「カラーケア」（トリートメントのみ）を選択する。
2. 表示タイプをシャンプーへ切り替える。
3. シリーズ選択肢からカラーケアが消え、画面では「すべて」と表示される。
4. 内部にはカラーケア条件が残るため、シャンプーが0件になる。

## 修正

- 種類切り替え時にシリーズ条件を検証し、その種類に存在しない条件だけ解除。価格などの有効な条件は保持。
- ブランドを開くと検索語・旧シリーズ・追加フィルターを引き継がず、そのブランドの商品を表示。
- plus eauのブランド画面に、メロウ・メルティ（ピンク）・リポア・リポルムの直接選択ボタンを配置。検索不要で選択できる。
- 選択肢に種類に応じた商品数を表示。シリーズの直接選択ボタンは検索語・追加条件を解除して当該シリーズを表示。
- 表示中の商品タイプ・追加条件数を表示。「このブランドの全商品」でブランドを保ち、両方・条件なしへ戻せる。
- シリーズ選択時に再描画でフォーカスが失われる問題を修正。
- ブランド入口で見出しへ移動。詳細から戻ると選んでいたシリーズ・ページは保持。
